Privacy policy

Last updated: 18 October 2026 · Draft for project review

After Mission is an independent student project created for educational and science-communication purposes. It is not an official NASA website and is not endorsed by NASA.

Information this version collects

The current prototype does not ask visitors to create an account, submit a form, or provide personal information. Game progress is handled in the visitor's browser session. The project team does not intentionally request sensitive personal information.

Hosting and server logs

This site is intended to be hosted using GitHub Pages. GitHub may process technical information, such as IP addresses and request logs, to provide, protect and maintain its services. Review GitHub's current privacy statement for details: GitHub Privacy Statement.

External links and media

The museum links to NASA and other external resources for research and attribution. When you follow an external link, that site's own privacy practices apply. Before launch, the project team must review any externally hosted images, fonts, analytics or embedded services added to the site. This draft does not claim that third-party services collect no data.

Children

This educational prototype is not designed to collect personal information from children. No account or submission feature is provided in this version.

Changes to this policy

This policy must be updated if the site adds analytics, contact forms, accounts, user-submitted content or other features that change what information is processed.

Contact

Before public launch, the project team should add a monitored project contact address here. No contact address has been published in this draft.

PRE-LAUNCH REVIEW REQUIRED. Confirm the deployed code, GitHub Pages settings and all third-party requests against this policy, and add a suitable contact method before public release.
